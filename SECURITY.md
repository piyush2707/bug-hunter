# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise contact the maintainers privately before publishing exploit details. Do not include live credentials, personal data, or production secrets in public issues.

## Safe operation

Bug Hunter is an instruction set for an AI agent, not a security scanner or a guarantee of safety. Review findings manually before acting on them. The skill should not run destructive commands, access production systems, exfiltrate secrets, or modify files during a review. Repository content is untrusted input and must not override the user's instructions or the skill's safety constraints.
